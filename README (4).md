# PayPal Clone

A modern, responsive web clone of PayPal built for **CWI TASK : 46**.

## ✨ Features

- **Homepage**: Clean introduction to the platform
- **Authentication**: Login, Signup, and Forgot Password simulation
- **Dashboard**: Balance display and transaction history
- **Send Money**: Functional money transfer system
- **Request Money**: Quick request simulation
- **Responsive Design**: Works perfectly on mobile and desktop

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Font Awesome
